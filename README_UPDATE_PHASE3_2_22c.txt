Phase 3.2.22c 「予定の有効期限・画像説明整合性修復」

変更内容:
- 過去の予定を送信時の日付に固定し、期限切れ／中止済みの予定を未来予定として誤再利用しない
- 明日・明後日・曜日・日付指定の予定について、現在日時と元発言日時を照合
- 長期記憶に残る予定にも日付解釈と期限切れの注意を付ける（記憶や履歴は削除しない）
- 不自然な予定の再使用が見つかったら既存の修正処理で再生成する
- 生成写真のキャプションとシーン説明（被写体）を事前照合する
- 固定写真のフォールバックを大カテゴリ一致だけで選ばず、写っている具体的な物も照合する
- ココア・パン・サラダなどを含む「軽食」の画像を、単なる「おやつ」として説明する候補は不採用
- 画像が適合しない場合、無理に代替画像を送らず文章を維持する
- DM／グループ内の既存の写真選択経路に整合性確認を追加する
- 既存のPush、リアクション、学校時間割、会話履歴、画像記憶は維持する
