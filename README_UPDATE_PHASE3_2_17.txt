追加:
- キャラクターのメッセージを長押しして 👍 / 😂 / 😊 / 😮 / 🙏 / 👏 のリアクションを付与
- 同じリアクションを再選択すると解除、別リアクションで置換
- 長押しメニューの「返信」から引用返信を開始
- 入力欄上部に引用元プレビューを表示し、×で解除可能
- テキスト・写真・スタンプ送信のすべてに引用を付与可能
- DM / グループの双方に対応
- ましろのリアクションは軽い会話コンテキストとして保持し、リアクションだけで即返信は発生させない
