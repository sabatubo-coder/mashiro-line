ましろLINE 3.2.13 前準備b「既存絵柄ベースの正式スタンプ画像化」

この更新はPWA側のみです。Replitのserver.mjsは変更しません。

正式スタンプ構成
- 既存8種を維持
  おはよう / わはは / OK / ありがと / おつかれ / びっくり / ねむい / またね
- 追加10種を正式な透過PNGスタンプへ置換
  おやすみ / ごめん / うれしい / しょんぼり / 困った / 拍手 / おなかすいた / いただきます / 大丈夫？ / がんばれ
- 合計18種

互換性
- 前準備版で使ったスタンプIDをそのまま維持しています。
- すでに送信済みの追加10種ミニスタンプも、今回の更新後は正式画像で表示されます。
- PUSH_VERSION は3.2.12aのまま維持しています。Backend更新は不要です。

更新手順
1. このPWAフォルダ一式でGitHub Pages側を上書き
2. Safariで https://sabatubo-coder.github.io/mashiro-line/?v=3213prepb を一度開く
3. スタンプ選択画面で合計18種が画像スタンプとして表示されることを確認
4. ホーム画面版ましろLINEを完全終了
5. ホーム画面版を再起動

補足
- Service Workerのキャッシュ名を今回専用へ更新し、追加10枚のPNGもキャッシュ対象に登録しています。
- 3.2.13本実装時に、キャラクターごとの自発スタンプ使用傾向をこの18種へ割り当てます。
