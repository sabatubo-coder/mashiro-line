【Phase 3.2.15】
- 優先5人: 夏樹 / 四季 / イチ / ブンジ / ソウスケ
- 一部の自発LINEを「小さな日常イベント」として継続可能にする
- 例: 出かける→結果報告、食べる/作る→感想、勉強/ゲーム開始→終了後の一言
- 1イベントは最大3段階、最長6時間で終了
- 継続中は通常の数時間クールダウンより短い20〜90分前後の次段階を選べる
- ましろから直近に返信がある場合は割り込まず通常会話を優先
- 継続段階は独立した新規自発回数としては数えない
- 内容に一致する場合のみ、途中経過を写真付きで送ることがある
- 継続中にスタンプを使っても本文は消さない
- 重大な事件・設定にない趣味・勝手な約束を連続イベントとして作らない
- 千秋 / 朔 / ユナは既存機能を維持し、今回の連続イベント対象外

既存会話履歴・記憶・画像・スタンプ・リアクション・引用返信は削除不要です。
