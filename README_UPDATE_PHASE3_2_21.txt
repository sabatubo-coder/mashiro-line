MashiroLine Phase 3.2.21 PWA 更新手順

1. PWAフォルダ一式を GitHub Pages 側へ上書き
2. Safariで https://sabatubo-coder.github.io/mashiro-line/?v=3221 を一度開く
3. ホーム画面版「ましろLINE」を完全終了して再起動

主な変更:
- 会話の自然な終端・再開 Ver.1
- 会話が完了した時は無理に新話題を続けず、短文 / スタンプ / リアクション / ごく低確率の既読のみで終了
- ましろが新しく送信した時点で一段落状態を解除
- 一段落後は自発LINEを30分〜2時間抑制
- 「またあとで」等の再開予定を保持して自然に回収
- Push受信 / 遅延返信 / 前面時自発LINEでも状態を同期
- 3.2.20のaway状態、3.2.19の複数吹き出し・1メッセージ1Pushを維持
