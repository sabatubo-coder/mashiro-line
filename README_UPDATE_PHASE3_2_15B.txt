MashiroLine Phase 3.2.15b
入力中表示・返信タイミング連携修復

更新手順
1. Backend/server.mjs で Replit の既存 server.mjs を上書き
2. Replit を再起動
3. /health を開き、version が次になっていることを確認
   phase3.2.15b-typing-reply-timing-link-v1
4. PWA フォルダ一式で GitHub Pages を上書き
5. Safari で次を一度開く
   https://sabatubo-coder.github.io/mashiro-line/?v=3215b
6. 正常表示を確認
7. ホーム画面版ましろLINEを完全終了し、再起動

主な修正
- DMの遅延返信で、返信予定時刻の少し前から「〇〇が入力中…」を表示
- グループ遅延返信も、返信時刻になってからではなく直前から該当人物名で入力中表示
- 短文は短め、長文はやや長めに、文字数＋小さな揺らぎで入力中時間を調整
- リアクションだけの場合は入力中表示を出さない
- スタンプだけの場合も入力中表示を出さない
- トークを開き直した時、まだ入力中時間帯なら表示を復元
- 別トークへ移動した際に古い入力中表示を持ち越さない
- 即時返信・自発DM・グループ自律会話も文字数ベースの入力中時間へ統一
- API生成待ち時間をそのまま長い「入力中…」として見せず、本文送信直前の入力時間として表示
- 3.2.15aまでの引用精度・DM重複防止・自発画像・スタンプ・リアクション・日常イベント連続性を維持
