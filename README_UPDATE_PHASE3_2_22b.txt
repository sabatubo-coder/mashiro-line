Phase 3.2.22b 自発話題の多様化・キャラクター横断重複防止

変更内容:
- 夏樹・四季・イチ・ブンジ・ソウスケの自発DM話題カテゴリを広げ、最近少ない話題を優先
- 学校・友達・動画・ゲーム・音楽・食べ物・寄り道・行事・読書・素朴な疑問など15カテゴリ
- 5人のDM自発メッセージ・通常返信から具体題材の重複を内部的に検出
- 「消しゴム」「ノートの端の落書き」など同じ狭い題材は7日間を目安に抑制
- 本の同一架空タイトルは30日間を目安に照合（本文は照合用の短いハッシュへ変換）
- 文房具・読書など同カテゴリの過度な集中も時間をまたいで抑制
- スマホ前面時の自発送信・Push自発送信の双方に対応
- 不採用の場合は別ジャンルへ再生成。改善しない場合は送信を見送り
- 他キャラクターの個別会話をAIへ渡さず、話題カテゴリの匿名集計だけを使う
- 確立済みの継続イベント・再開予定は優先し、機械的に切らない
- 既存の会話履歴・通知・生成画像・学校時間割・リアクション管理を維持
