Phase 3.2.22 学校時間割・休み時間 Ver.1

主な変更:
- 月〜金の固定時間割（朝HR、1〜6限、10分休み、昼休み、終礼）を導入
- 授業・HR中は原則未読。次の休み時間・昼休み・放課後に確認
- 休み時間ごとにキャラクター別のスマホ確認傾向を反映
- 休み終了間際は既読だけ付き、返信を次の休み時間へ持ち越す場合あり
- 同じ学校の優先5人は同じ時間割を共有し、返信時刻は休み時間内でばらつく
- 昼休みは返信しやすい。夏樹はましろと直接一緒にいる可能性があるため自発LINEは控えめ
- 授業中にましろが送ったLINEだとキャラクター側が認識（毎回は言及しない）
- 土日は休日。祝日・長期休暇・行事対応は今後の拡張
