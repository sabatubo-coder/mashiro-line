ましろLINE Phase 1.7.1 自発メッセージ 初回テスト修正版 - PWA

修正内容:
Phase 1.7では、既存トークの最後が夏樹だった場合、
「夏樹からの連投防止（3時間）」が初回2〜5分テストにも適用され、
初回メッセージが届かないことがありました。

Phase 1.7.1では:
- 初回動作確認の1通だけ、既存トークのクールダウンを無視
- 初回成功後は従来どおり90〜240分の不定期運用
- 1日最大4通、22:30〜7:00は送らない
- 通常時の連投防止はそのまま維持

更新手順:
1. GitHubの mashiro-line にこのZIP内のファイルを上書き
2. Commit changes
3. 数分待つ
4. Safariで:
   https://sabatubo-coder.github.io/mashiro-line/?v=171
5. ホーム画面PWAを完全終了→再起動
6. ましろ側から何も送らず2〜5分待つ

初回の自発メッセージが1通来れば成功です。
