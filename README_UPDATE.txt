ましろLINE Phase 1.7.2 自発メッセージ 状態リセット修正版

原因:
Phase 1.7 / 1.7.1 で一度自発メッセージ判定が延期されると、
PWA内に保存された nextDueAt が数時間先のまま残っていました。
1.7.1へ更新しても同じ保存キーを使っていたため、
初回テストが2〜5分では実行されない場合がありました。

修正:
- 自発メッセージ状態の保存キーを新しくして、古い延期時刻を無視
- 初回確認だけ1〜2分後に実行
- 初回成功後は通常どおり90〜240分のランダム間隔
- 1日最大4通、22:30〜7:00停止、連投防止は維持
- BackendはPhase 1.7.1のままでOK

更新手順:
1. GitHubの mashiro-line にこのZIP内のファイルをすべて上書き
2. Commit changes
3. 2〜5分待つ
4. Safariで:
   https://sabatubo-coder.github.io/mashiro-line/?v=172
5. ホーム画面のPWAを完全終了して再起動
6. ましろ側から何も送らず、アプリを前面で2〜3分待つ

夏樹が「入力中…」になり、自発メッセージが1通来れば成功です。
