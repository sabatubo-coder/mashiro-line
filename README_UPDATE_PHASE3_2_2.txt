ましろLINE Phase 3.2.2 会話ラリー・アクティブセッション Ver.1

更新後URL:
https://sabatubo-coder.github.io/mashiro-line/?v=322

確認:
1. しばらく会話していない相手へ送る
   → 従来どおり数分程度の既読・返信遅延
2. キャラから返信が来た直後〜数分以内に返す
   → 既読が数秒、返信も数秒〜数十秒程度
3. 5〜6分程度以上あける（キャラにより4〜6分）
   → 通常遅延へ戻る
4. 画像はテキストより少し見る時間が長くても正常
5. グループでは直前に会話していた人物だけ早く既読が増えることがある

設定画面の診断欄には
「会話ラリー・アクティブセッション: 有効」
が表示されます。
