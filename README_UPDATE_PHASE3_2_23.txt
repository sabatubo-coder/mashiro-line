Phase 3.2.23「夏樹の軽口・照れた直接回答 Ver.1」

目的:
- 夏樹が軽い冗談や少し照れる質問に「別の話しよ」と不必要に話題転換する挙動を減らす。
- 聞かれた質問には、まず短く自分の感想・考えを答える。照れながらも真面目に答える性格を維持する。
- 軽い言葉遊び・恋愛観・ツッコミは許容するが、露骨な性的描写や親密な行為の演技には踏み込まない。

変更:
- 夏樹のDM用性格指示に、軽い照れ・自然な軽口・質問への直接回答ルールを追加。
- 明示質問の応答チェックに、夏樹の軽い話題の一律回避を防ぐ指示を追加。
- 非露骨な軽い質問で「別の話しよ」等へ逸れた場合だけ、返信を再編集する処理を追加。
- 安全判定は変更しない。安全上扱えない内容を強制的に生成しない。
- 千秋・朔・ユナおよび他の4人の個別設定は維持する。
- 3.2.22cの学校時間割・予定管理・画像整合性・Push・記憶・会話履歴は維持する。
