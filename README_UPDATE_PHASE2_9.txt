ましろLINE Phase 2.9 オンライン状態・生活モデル連動

更新対象:
- GitHub Pages / PWA

BackendもPhase 2.9へ更新してください。

更新後URL:
https://sabatubo-coder.github.io/mashiro-line/?v=290

主な動作:
- 夏樹・四季・イチは常時「オンライン」表示ではなくなる
- 自発LINE・返信・既読など、実際のLINE活動直後だけ「オンライン」
- 夏樹: 基本約6分
- 四季: 基本約5分
- イチ: 基本約5分
- 授業・部活・通学・就寝などは、生活モデルに応じて表示時間が短くなる
- 活動が古くなるとヘッダーの「オンライン」は自動で消える
- グループ表示「6人」と、生活モデル未実装キャラの従来表示は維持

確認:
1. 夏樹・四季・イチのトークを開く
2. 直近の活動が古ければ「オンライン」が表示されない
3. メッセージが既読になった直後、または返信/自発LINE直後に「オンライン」
4. 数分待つと自動で表示が消える
