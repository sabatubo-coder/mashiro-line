2. Safariで https://sabatubo-coder.github.io/mashiro-line/?v=3220 を一度開く

- 明示的な離脱発言を実際の away 状態へ反映
- 入浴 / 食事 / 外出・買い物 / 勉強・作業 / 家の用事 / 移動 / 就寝の7系統

- 離脱中の既読・返信・自発会話・自発画像・グループ自律会話を抑制
