ましろLINE Phase 2.8.1 バックグラウンド既読・バッジ修正

今回はPWA側だけの修正です。
Replit Backendの更新・再公開は不要です。

修正内容:
- activeConversationIdが一致するだけでは既読にしない
- チャット画面が実際に表示中 + document.visibilityState=="visible" の時だけ既読
- トーク画面を開いたままホームへ戻った状態でPushが来ても未読を維持
- Service Workerが付けたアプリアイコンのバッジを、背景PWAが勝手に0へ戻さない
- 同じトーク画面へ復帰した時点で既読にし、バッジを解除
- トーク一覧へ戻った状態なら、該当トークを実際に開くまで未読を維持

更新後URL:
https://sabatubo-coder.github.io/mashiro-line/?v=281

確認テスト:
1. 夏樹/四季/イチのトークを開く
2. メッセージを送る
3. 返信が来る前にホーム画面へ戻る
4. Push返信が来たらアプリアイコンに「1」が付くことを確認
5. 通知をタップせずアプリを開いた場合:
   - 同じトーク画面が復帰すれば、その時点で既読になりバッジは消えてよい
6. トーク一覧でアプリを閉じた場合:
   - バッジは該当トークを開くまで維持される
